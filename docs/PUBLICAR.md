# Publicação do painel

A publicação na web ("Publicar na Web" do Power BI Service) não está disponível na conta institucional usada no projeto: a opção é bloqueada pelo administrador. O relatório fica só no workspace pessoal, privado. Ver [DECISOES.md](DECISOES.md), D27.

O painel é distribuído por:

- **Vídeo** de 78 s: `docs/video/raio-x-portuario.mp4`
- **PDF** com as 5 páginas: `docs/RaioXPortuario.pdf`
- **PBIP** para abrir no Power BI Desktop (gratuito): zip da [release](https://github.com/gorc-supply/raio-x-portuario/releases/latest), com passo a passo no README ("Como ver o painel")
